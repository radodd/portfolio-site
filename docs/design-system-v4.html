Motion Principles
Scroll-Driven
Components animate based on scroll position using Framer Motion's useScroll and GSAP ScrollTrigger, creating a narrative flow.
Spring Physics
Interactive elements use spring animations for natural, physics-based movement — nav indicator, liquid buttons, form bar, card reveals.
Continuous Ambient
Background blobs, gradient text, and D2 divider run continuously via CSS keyframes, adding life without requiring interaction.
Scale on Interact
Buttons: hover → 1.05 · focus → 1.08 · active → 1.02. Tags: hover → 1.05. Tactile feedback without layout shift.

Section 11 — Added in v4.0
Scroll Choreography

Every scroll-triggered animation mapped — timing, easing, delay, trigger threshold. Four governing principles, a complete timing table, and copy-ready implementation utilities.

Four Motion Principles
1. Entrance only
Elements animate in on scroll-enter. They do not animate out on exit. Everything stays where it landed — reverse-scroll animations feel unfinished.
2. Stagger over simultaneous
Multiple elements (cards, tags, bullets) stagger at 80–120ms. Simultaneous entrances flatten depth. Stagger implies sequence and hierarchy.
3. Up-and-fade is the default
Every element: opacity 0→1 · translateY(24px→0). Only hero name and section headings get custom treatment. Consistency creates cohesion.
4. Ambient runs always
Blob float, gradient shimmer, D2 breathe — CSS keyframes, always-on, never scroll-tied. They are the baseline energy. Scroll animations layer on top.

fadeUp(y, duration, ease)
y=24 · dur=0.55 · ease=EASE_IN_OUT
Default entrance. Used on every section element. Vary y for visual weight — 32px for Fraunces headings, 12px for body text.
fadeIn(duration)
dur=0.45

scaleUp()
scale 0.92→1 · SPRING_SOFT
Stat blocks, social links. Spring overshoot suggests the element is interactive or important.
slideFromLeft()
x -8→0 · 0.45s ease-out
Experience sidebar items + bullet points. Subtle x-axis travel mirrors the sidebar-navigation pattern.
scaleRule()
scaleX 0→1 · originX:0 · ease-out-expo
Section gradient rule bars. Draws in from the left edge — feels like underlining the heading.
stagger(children, delay)
children=0.08 · delay=0
Container variant. Wraps any list to stagger children automatically. Adjust children to 0.04 for fast items (pills) or 0.12 for slow (cards).
